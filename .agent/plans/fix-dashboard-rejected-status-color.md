# Samakan warna status Rejected di Dashboard Saya

## Perubahan
- Perbarui komponen badge status bersama agar semua status yang mengandung `Rejected` menggunakan tampilan destructive yang sama seperti di menu Admin Kendaraan.
- Terapkan konsistensi ini pada tabel Dashboard Saya dan panel detail request yang sudah memakai komponen badge bersama.
- Pertahankan warna status Approved, Submitted, Pending, dan Cancelled yang ada saat ini.

## Validasi
- Pastikan variasi status kendaraan seperti penolakan admin dan penolakan Plant Director tampil dengan warna Rejected yang konsisten.
- Pastikan badge status Extra Meal dan status non-Rejected tidak berubah.
- Jalankan validasi proyek setelah perubahan.
